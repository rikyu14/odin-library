# Library Project

**Live Preview:** https://rikyu14.github.io/odin-library/

This is a simple Library Project based on The Odin Project lessons. The application allows you to add, display, and manage books using JavaScript. Each book is stored as an object with a unique ID, and the library provides functionality to add new books, remove them, and toggle their read status.

## Features

- **Add New Book:** Use the "New Book" button to open a form and add a new book.
- **Display Books:** Books are displayed in a grid layout which adjusts automatically for different screen sizes.
- **Toggle Read Status:** Change the read status of a book with a single button click.
- **Remove Book:** Delete a book from your library.
